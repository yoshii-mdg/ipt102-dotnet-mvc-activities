# 📘 IPT102 – .NET MVC Activities

This repository contains a collection of hands-on activities, exercises, and sample implementations for **IPT102 (Introduction to Programming Technologies)** using the **ASP.NET MVC framework**. It is designed to help students understand the core concepts of web development with .NET, including MVC architecture, routing, controllers, models, views, data handling, and basic CRUD operations.

---

## 🎯 Purpose
The goal of these activities is to provide step-by-step practice in building modern, structured web applications while strengthening foundational programming skills. Each folder or project covers a specific concept to support learning throughout the course.

---

## 🛠️ Technologies Used
- **ASP.NET MVC (Model–View–Controller)**
- **C#**
- **.NET Framework / .NET Core** (depending on activity)
- **Razor View Engine**
- **Entity Framework** (for some activities)
- **HTML, CSS, Bootstrap**

---

## 📂 Repository Contents
You may find the following activities inside:
- Understanding MVC folder structure  
- Creating controllers & action methods  
- Building Razor views & layouts  
- Handling forms (GET/POST)  
- Model binding & data validation  
- Routing & URL patterns  
- Performing CRUD operations  
- Database integration using Entity Framework  
- Mini practice applications
